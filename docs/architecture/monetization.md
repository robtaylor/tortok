# Monetization

*Reference doc — **stub.** The full present-tense write-up of monetization (the
interface-first payout model, the first-party fan-allocated pool, external
creator monetization signals) is pending the post-migration area-doc backfill,
which checks every claim against the code. The decision record below is
authoritative for the design, and the open design questions live in
[`open-problems/monetization.md`](open-problems/monetization.md).*

This area covers how creators earn: tortok serves no ads and takes no cut, so
creators monetize externally using trustworthy engagement signals published by
their PDS, plus a first-party "support open content" pool. The V1 pool rail is
gated on Apple App Store guidance and the US-incorporation decision.

## Implementation status

Interface-first direction is set (Decision 0011); the payout-destination Lexicon
(sub-problem A) can ship in Phase 3, the first-party pool rail is gated. No rail
is implemented yet. Verified current-state write-up is part of the adoption
follow-up.
